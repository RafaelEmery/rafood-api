| `ci.environment.json`                | Environment for CI/local Newman runs (`baseUrl`, geo coordinates). |

## Smoke tests (Newman)

The smoke collection runs a **13-step** flow under the `Smoke` folder:

1. Health check (`GET /ping`)
1. Create user → category → restaurant (+ weekday/weekend schedules) → product → offer (+ schedule for today)
1. List/get restaurants and near-by endpoints (`/restaurants/open`, `/offers/active`)

Variables are chained via collection variables (`userId`, `restaurantId`, etc.) and Postman test scripts assert status codes.

### Local run

With the API and database up (`make start`):

```bash
npx --yes newman run postman/smoke.postman_collection.json \
  -e postman/ci.environment.json \
  --folder "Smoke"
```
